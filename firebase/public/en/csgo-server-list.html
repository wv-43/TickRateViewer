Reading the list

  • Available: the server is waiting for the next match and gets assigned as soon as players are found.
  • Starting a match: players have accepted and are connecting.
  • Match in progress: the game is on; map and score update every round.
  • Mode: some servers are reserved for 5v5, Wingman or 1v1, so a short game never blocks a 5v5 server.

The list refreshes every 30 seconds, and server status is recomputed every minute.

Why no IP to copy?

On a classic CS GO server list you copy an IP and join whoever is there. Here, each server is reserved for one match, with a password unique to that game, so nobody can drop in halfway. To play, queue on the site: when your match is ready, the Connect button launches CS:GO straight onto the right server. See 128 tick CS GO server for how it all works.
