Créer un serveur CS GO dédié en 2026

Le guide que nous suivons pour nos propres serveurs, simplifié : installer un serveur dédié CS GO (version legacy) sous Linux, obtenir un jeton Steam, le lancer en 128 tick et le configurer.

Créer mon compte gratuitVoir les modes de jeu

Ce qu'il faut

  • Une machine Linux (un VPS suffit) avec une bonne connexion. Compte environ 40 Go de disque pour le jeu.
  • SteamCMD, l'outil en ligne de commande de Valve pour installer les serveurs de jeu.
  • Un jeton de serveur Steam (GSLT), gratuit, lié à ton compte Steam.
  • Les ports UDP ouverts : 27015 par défaut pour le jeu, et un port pour GOTV si tu l'utilises.

1. Installer le serveur avec SteamCMD

Le serveur dédié de CS:GO s'installe avec SteamCMD, en connexion anonyme :

steamcmd +force_install_dir ~/csgo-ds +login anonymous +app_update 740 validate +quit

Depuis que CS:GO legacy est une application Steam à part (mars 2026), le serveur doit s'annoncer avec l'App ID de la version legacy, 4465480. Sur nos serveurs, nous écrivons cet App ID dans le fichier steam_appid.txt du dossier du serveur et dans la ligne appID= de csgo/steam.inf, avant chaque démarrage (une mise à jour peut remettre l'ancienne valeur).

2. Obtenir un jeton Steam (GSLT)

Sans jeton, ton serveur n'apparaît pas correctement aux joueurs. Va sur la page de gestion des serveurs de jeu de Steam (steamcommunity.com/dev/managegameservers), indique l'App ID 4465480 et génère un jeton. Il en faut un par serveur. Garde-le secret : il est lié à ton compte.

3. Lancer le serveur en 128 tick

./srcds_run -game csgo -console -usercon -port 27015 -tickrate 128 +game_type 0 +game_mode 1 +map de_mirage +sv_setsteamaccount TON_JETON

Le paramètre -tickrate 128 fait tourner le serveur à 128 tick (voir c'est quoi le tickrate). Le couple game_type / game_mode choisit le mode :

4. Le fichier server.cfg

Dans csgo/cfg/server.cfg, les réglages de base :

hostname "Mon serveur CS:GO 128 tick"
rcon_password "un_mot_de_passe_long"
sv_password ""            // mot de passe pour rejoindre, vide = public
sv_lan 0
sv_cheats 0

Pour la liste des commandes utiles en jeu et en console, voir notre page commandes CS:GO.

5. Faire tourner le serveur en continu

Lance le serveur comme un service (systemd sous Linux) pour qu'il redémarre tout seul après un plantage ou un redémarrage de la machine, et fais tourner SteamCMD régulièrement pour les mises à jour.

Ou jouer sans rien héberger

Héberger un serveur CS:GO coûte du temps et de l'argent, et il faut encore trouver des joueurs. Si tu veux juste jouer des matchs équilibrés, TICKRATE fournit un serveur CS GO 128 tick pour chaque partie, gratuitement.

Questions fréquentes

Quel App ID pour le serveur CS:GO legacy ?

Le serveur dédié s'installe avec SteamCMD sous l'App ID 740. Le jeton de serveur (GSLT) se crée avec l'App ID de CS:GO legacy, 4465480.

Un serveur CS GO peut-il tourner sous Windows ?

Oui, le serveur dédié existe aussi pour Windows, mais la plupart des hébergeurs utilisent Linux, plus léger.

Combien de joueurs par serveur ?

Un serveur compétitif accueille 10 joueurs. Le nombre maximum se règle avec le paramètre de lancement -maxplayers_override.

Le 128 tick demande-t-il une grosse machine ?

Il demande plus de processeur que le 64 tick, surtout à 10 joueurs. Un cœur rapide par serveur est conseillé.
